# Data Analytics Dashboard

A practical sales analytics project using Python, Pandas, SQL, and business KPI analysis.

## Key Metrics

- Total Sales: $19,680
- Total Profit: $4,089
- Total Orders: 18
- Total Quantity Sold: 118

## Technologies

- Python
- Pandas
- SQL
- CSV
- Data Analysis

## Analysis

The project analyzes:

- Sales performance by region
- Profit by product category
- Product-level sales
- Overall sales and profit KPIs
